🎉 Event Management System

A desktop application built with Java and JavaFX that allows users to create, manage, and participate in events through a role-based system.

📖 Overview

The Event Management System is a desktop application developed using Java and JavaFX that allows users to create, manage, and participate in events. The system supports different user roles, each with its own set of features and permissions.

The graphical user interface was designed using JavaFX Scene Builder with FXML, while the application logic was implemented in Java following object-oriented programming principles.

✨ Features

👤 Admin

Manage users

View all events

Monitor organizers and attendees

🗓️ Organizer

Create new events

Update event details

Manage events

View registered attendees

🎟️ Attendee

Register and log in

Browse available events

Register for events

Cancel registrations

View registered events
